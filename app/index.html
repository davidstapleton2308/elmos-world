ELMO'S INPUT · EXPERIMENTAL

Game controller compatibility

Choose how a specific game receives your controller. Native input is the default. Virtual Xbox is opt-in and may help older XInput-only games recognize a PS4 controller.

Controller profiles are stored locally, per game.

Virtual Xbox needs an existing compatible ViGEmBus driver. It never silently installs one. If a game receives duplicate presses, review your other controller remappers and consider HidHide. PS opens Elmo's game menu.

Returning to Elmos World

Press PS once to bring up the game menu while a game is running. Ctrl+Alt+G remains as a keyboard recovery shortcut. Escape belongs to the game and never closes it. The PS button may be intercepted by Steam or Windows Game Bar; the test panel can help find its raw button number. F11 toggles fullscreen. In browser mode use Alt+Tab. On the library screen, press your controller's Back/Circle to return from game details. A controller combo cannot reliably overlay every exclusive-fullscreen game without a separate system-level input service.

Controller navigation

DualShock 4: D-pad / left stick moves focus; Cross selects; Circle goes back; Options starts the highlighted game. L1 / R1 cycle through Library, Needs Review, Emulators, and Settings. F11 toggles fullscreen. The native SDL reader does not remap controls inside games.

Controller compatibility

Elmos World supports controllers in its own interface. Games that natively support a PS4 controller can receive it directly. Games accepting only XInput may still need an external translation driver or game-specific configuration. Elmos World does not silently install drivers or elevate downloaded games.
