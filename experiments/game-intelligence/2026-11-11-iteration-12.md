Actual current source: `_steam_manifest` checks presence of `steam_appid.txt`, `goggame-*.info`, or `appmanifest_*.acf` by filename, not trusted installed-store ownership. `_game_signatures` counts that as +20 structural evidence. `_result` marks score >=96 ready when stable. ## Hypothesis
Separate arbitrary manifest hints from trusted installed-store records and require an exact (store namespace, product ID) match to an independently supplied inventory record before claiming a canonical game identity. If manifest and trusted inventory disagree, abstain. Store edition SKU only when the trusted inventory identifies it.

## Executed synthetic experiment
Executed Python 3 prototype in isolated environment with 10 deterministic cases, no filesystem changes. Catalog was a synthetic oracle mapping (Steam 620 Portal 2; Steam 400 Portal; Steam 870780 Control Ultimate; GOG 123 Control base). Fixtures: five verified identities, spoofed Steam claim, conflicting manifest, unlisted utility, absent manifest, cross-store mismatch. Compared naive catalog lookup by manifest to a gated lookup requiring an independent matching installed-store record.

Observed naive: TP 5, FP 3, FN 0; precision 5/8=62.5%, recall 5/5=100%. Gated: TP 5, FP 0, FN 0; precision 5/5=100%, recall 5/5=100% on **these fixtures only**. No real store record parser was implemented. An unverified edition text claim was ignored in favor of the synthetic trusted SKU. Measured loop duration ~0.021 ms, too small for meaningful performance inference. Emulator classification, artwork correctness, and actual false file moves were **not tested**. All filesystem moves = zero.

## Critical caveats
The trusted inventory record was provided by the fixture oracle; this tests policy behavior, not how accurately a real inventory can be discovered. Baseline is a naive manifest-to-catalog resolver, **not** full current Smart Discovery classification. Do not transfer these precision figures to production. Real Steam appmanifest location/format, GOG Galaxy records, Epic manifests, portable games without store IDs, and edition ambiguity need independent validation. Presence of `steam_appid.txt` is a claim, not ownership proof.
