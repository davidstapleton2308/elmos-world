# Game Intelligence Lab — iteration 10 (2026-11-11)

## Source and hypothesis
Read current main `app/smart_discovery.py` (blob e0fc204f7d022af6eef746e73c2f5d538befe22b) and iteration 09 through the GitHub connector. The current `_identity(title,exe)` takes the **maximum** of character similarity and token overlap. `inspect_folder` combines that identity with engine/manifest/assets structure, and `_result` marks scores >=96 as ready. None of these establishes an edition-specific canonical game identity.

Hypothesis: generic executable similarity creates misleading high confidence for different sequels, and exact game executables cannot by themselves distinguish editions. This contaminates downstream artwork selection if the inferred title is treated as a verified ID.

## Executed reproducible synthetic fixture
A disposable Python test reproduced the character-similarity and token-overlap scoring (without KNOWN_EXES overrides) on ten title/executable pairs, five deliberately mismatched identities and five matching base-game identities. No binaries were downloaded or executed; no filesystem moves occurred.

Ground truth is fixture-defined, not measured from real releases.

## New design: canonical identity graph
Separate (a) executable/game-family detection, (b) base game identity, (c) edition identity, (d) platform/store and (e) artwork asset identity. Store IDs should be typed and namespaced (`steam:appid`, `gog:product_id`, `epic:namespace:item_id`, `igdb:game_id`); never merge on title string alone. Manifest filenames/content from untrusted downloads are claims, not independently verified store ownership. For edition distinctions, prefer trusted installed-store records or signed publisher metadata when available; otherwise retain `edition=unknown`. Cover, hero, logo and icon must resolve against the chosen canonical base/edition and retain source/provenance; artwork ambiguity should trigger review instead of silently selecting the first match.

Suggested metamorphic invariants: (1) swapping 'Portal' with 'Portal 2' must not retain verified canonical identity solely due to similar executable; (2) adding 'Deluxe Edition' to a folder name must not upgrade edition confidence; (3) changing release-site suffixes must not change the canonical base game; (4) spoofed `steam_appid.txt` must not independently authorize a move; (5) artwork for different numbered sequels must not share a canonical asset ID.
