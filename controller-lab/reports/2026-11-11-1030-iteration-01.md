## Specific defect
Gyro-to-mouse converted each frame's floating delta directly to `int(round(...))`. At 120 Hz, a 0.2-pixel/frame signal becomes zero indefinitely, even though 5 frames should produce one pixel. This produces poor low-speed gyro aiming.

## Change
- Add `mouse_motion.MouseDeltaAccumulator` with bounded, finite-input-safe fractional residuals.
- Integrate one per Mapper for gyro-to-mouse; reset residual when gyro mapping switches away from mouse.
- Add unit tests for subpixel preservation, reversal/no drift, reset, nonfinite input and bounds.

## Algorithm
For each axis, let `r` be fractional residual and `d` the incoming floating relative motion: `q=trunc(r+d)`; emit `q`; set `r=r+d-q`. The residual is bounded in (-1,1), avoiding per-frame quantization loss. Gyro scaling remains angular velocity × bounded frame duration × sensitivity. The implementation resets on invalid input or when the mode changes away from mouse.

## Evidence / verification
