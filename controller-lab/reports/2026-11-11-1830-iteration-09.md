## Change: healthy-frame lease
Added `HealthyFrameLease`, used by `command_emulate`. Each successful physical controller poll and mapping now submits a gamepad frame to the lease scheduler:
1. First or changed gamepad state: transmit the full state immediately.
2. Unchanged gamepad state: send no report until one second has elapsed since the last successful send.
3. At one second: issue an acknowledged heartbeat for the existing slot, without altering button state.
4. Failed state transmission or heartbeat: propagate the exception; never record successful contact.
5. Never use an independent heartbeat thread. A failed/disconnected SDL read prevents new heartbeats, so the existing three-second watchdog can expire the virtual device.

The cached state is a deep copy to prevent nested mutable axis/button values from hiding changes. Keyboard/mouse reports remain on their original path to avoid accidentally suppressing relative movement or scroll deltas.

## Source and research
SDL3 official API documents identify connected gamepads by instance IDs, not enumeration indices:
- https://wiki.libsdl.org/SDL3/SDL_GetGamepads
- https://wiki.libsdl.org/SDL3/SDL_GetGamepadID
The project already pins the SDL physical instance ID; the new lease scheduler runs only after `source.read_instance(physical_instance)` succeeds.
