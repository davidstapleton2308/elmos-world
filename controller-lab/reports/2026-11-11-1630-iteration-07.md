## Engineering problem
The bridge watchdog uses a System.Threading.Timer ThreadPool callback. An unexpected exception escaping this callback can terminate the .NET process, potentially disrupting all virtual controllers. The prior code caught per-device disposal exceptions but not failures in iteration, elapsed-time calculations, or event emission. A failed diagnostic emit inside the disposal catch could also escape.
