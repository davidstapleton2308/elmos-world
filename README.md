# Elmos World
A controller-friendly Windows game launcher with game discovery, artwork, library management, and an in-app Update Center.

## Build
Open **Actions → Build Elmos World Windows Setup → Run workflow** to build the Windows installer. The workflow also runs on version tags (`v*`).

## Releases
After a successful build and Windows installation test, create/push tag `v3.1.1` to publish the installer, portable ZIP, and SHA-256 checksum as a GitHub Release.

The app checks releases from `davidstapleton2308/elmos-world`.
