ELMOS WORLD 3.1.1 — UPDATE CENTER

New: Settings > Elmos World Update Center.
- Check latest version from your configured public GitHub repository.
- Read release notes and choose Update & Restart.
- Download versioned Setup.exe and verify its SHA-256 checksum.
- Block updating when a game session is active.
- Create a local settings backup before installation.
- Close Elmos World, install over the existing application, and relaunch.
- GitHub Actions builds Windows Setup and publishes versioned tagged releases.
